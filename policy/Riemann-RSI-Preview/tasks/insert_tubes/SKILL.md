# Public tube insertion composition

Read `workflow.json`, then the selected task-owned skill contracts. The task directory contains the callable skills, dispatcher and runtime bindings. Shared perception, hardware geometry, motion and command contracts live under `skills/shared`. There are no copied official runtime files, unrelated task modules or whole teacher aliases.

Use the current public scene to qualify a source and receiving goal. Compose actual grasp, lift, post-lift upright route and insertion tools, followed by bounded public reseat/recovery and the original own resets. Preserve mature execution semantics, not just equivalent final targets. Own command completion and public normalized gripper feedback never establish contact or official success.

[composition.json](composition.json) declares the executable bindings; Git identifies
the source version. [entry.py](entry.py) runs the common official client.
See the [runtime contract](../../docs/official-runtime.md) and
[installation and launch instructions](../../README.md).
