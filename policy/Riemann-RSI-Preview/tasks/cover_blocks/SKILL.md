# Cup covering and uncovering skills

The restricted public controller composes six task-owned skills through `workflow.json`: observe current cup/block surfaces, apply the mature transfer recipe, execute one bounded transfer, acquire an actual wrist view, review release imagery and resolve the next stage. The initial left-to-right cup binding, red/green/blue uncover order, original public cup homes, both own-joint resets and settling dwell remain explicit.

Shared code contains only declared public geometry, own tool calibration, dense gripper sampling, trajectory execution and feedback contracts. No old task generator, teacher, copied simulator, compatibility alias, layout or reward interface is required. `entry.py` runs the common official client; the official SDK performs execution and scoring.

[composition.json](composition.json) declares the executable bindings; Git identifies
the source version. [entry.py](entry.py) runs the common official client.
See the [runtime contract](../../docs/official-runtime.md) and
[installation and launch instructions](../../README.md).
