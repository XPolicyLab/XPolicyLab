# Cover and uncover visible blocks with cups

## Applicability

Use when the actual instruction asks for cup covering and uncovering, and current public images support those objects. This is procedural knowledge, not scene evidence or a completed-stage record.

## Staged decisions

- Pair the initially visible cups and blocks in their observed left-to-right order; keep the cup-to-colour binding for this episode.
- Cover all visible blocks before beginning the uncover sequence. Maintain the cup orientation, closed carry, supported release and retreat.
- Uncover red, green and blue in that order. Return each cup to its own initially observed home rather than to an arbitrary empty location.
- Restore both arms to their observed initial joint states and settle with open commands.

## Evidence and recovery

- Reobserve a moving cup before pickup. An initially observed home is a return goal, not its current pose.
- Use actual action-bearing tool receipts for stage progress; a zero-action selection cannot establish a cup home or complete a transfer.
- A closed command or reached robot pose does not establish a secure grasp or task completion.
- If the object slips, becomes occluded or the relation is uncertain, reacquire a view before a bounded correction.
- Do not repeat an ineffective command indefinitely; use the shared action budget and preserve visible partial progress.
