# Random block stack

The external `workflow.json` executes the original random three-block program,
including its single typed recovery; `workflows/source.json` executes its mutable
seven source attempts. Eleven functional capabilities contain no full-task
legacy runner. Each capability has one `SKILL.md` and one `implementation.py`.

Dense sample constants are not official action counts: the original sparse
clock consumes five close controls and three release controls at the native
ten-substep interval. The official 550-control horizon is unchanged.

`resources.json` declares external hash-pinned public robot/RGB resources.
[composition.json](composition.json) declares the executable bindings; Git identifies
the source version. [entry.py](entry.py) runs the common official client.
See the [runtime contract](../../docs/official-runtime.md) and
[installation and launch instructions](../../README.md).
