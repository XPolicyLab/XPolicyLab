# Charger rule capabilities

Execute the declared external `workflow.json` through the generic declarative workflow executor.
Each capability is documented beside its implementation.py. Skill boundaries retain the mature
grasp, carry, insertion, gripper and own-joint home actions; no WAM selection occurs between them.

Control inputs are current RGB, own robot state, fixed calibration and public asset templates.
Layouts, scores and GT remain evaluation-only. Workflow completion is not official success.
