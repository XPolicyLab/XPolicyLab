# Random bowl stack composition

Entry: `entry.py`. Controller: `controller.py:CalibratedBowlContext`. Execute `workflow.json` and `workflows/transfer.json` through the shared bounded interpreter. The task owns ten functional capability directories; the official evaluation, camera synchronization, recording, sampler and shutdown are shared evaluator support rather than online task skills.

The actor receives only public RGB, public robot observations, declared public robot geometry/planning tools, and internal command memory. No WAM, Qwen, resolver or full environment handle is used. External resource identities are checked; Git versions the source and executable declarations.

[composition.json](composition.json) declares the executable bindings; Git identifies
the source version. [entry.py](entry.py) runs the common official client.
See the [runtime contract](../../docs/official-runtime.md) and
[installation and launch instructions](../../README.md).
