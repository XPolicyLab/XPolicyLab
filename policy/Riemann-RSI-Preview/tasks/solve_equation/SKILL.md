# Equation skill workflow

Claim `controller.applicable(public_instruction)` once and use
`controller.execution()` with exact native tool receipts. Current RGB symbol,
source and pad geometry still qualify the unchanged original transfer. The
workflow owns conditional relay and both home boundaries without resolver
reselection, with two safe view/home preparations per transfer stage. Partial
irreversible execution stops with its phase, never replaying. Original internal
interpolation, close/release/dwell, empty-grasp reset, endpoint fallback and
measured vertical retreat remain unchanged.

Use the declared motion and bounded recovery stages. Cross-arm relay is conditional. Tool completion or gripper command dwell is not contact or official success. No old generator, compatibility alias, copied official runtime or unrelated task module remains.

[composition.json](composition.json) declares the executable bindings; Git identifies
the source version. [entry.py](entry.py) runs the common official client.
See the [runtime contract](../../docs/official-runtime.md) and
[installation and launch instructions](../../README.md).
