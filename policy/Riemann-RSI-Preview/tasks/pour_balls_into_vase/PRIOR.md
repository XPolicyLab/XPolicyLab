# Original public vessel rule

Use the declared mature capability chain for this mode: qualify current views,
restore observation arms, recover visible balls, grasp and lift, perform a
conditional relay, carry upright, reobserve the moving rim, pivot and drain,
reverse upright, return and release the cup, then restore both arms and perform
the bounded post-pour recovery. Keep a fresh public observation for each control.

Grasp retries and view reacquisition stay finite and in the same episode. Own
jaw command responses and visual attachment hypotheses are not contact sensors.
No object templates, layouts, scorer state or real finger measurements are
policy inputs. No resolver, Qwen or WAM selects another execution mode.
The official evaluator alone scores.
