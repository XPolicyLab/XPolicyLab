# Language-directed block stacking

`LanguageStackContext` composes ten callable task capabilities. `workflow.json`
drives initial opening, central target selection and three continuous
colour-ordered pick/place operations. Preserve the declared grasp, carry, retry
and home stages.

Public normalized jaw feedback is advisory; physical finger width and contact
are unknown. Missing contact evidence follows the declared continuation rather
than inventing a measured width. The official task/scorer decides success;
the workflow does not select a learned fallback.

[composition.json](composition.json) declares the executable bindings; Git identifies
the source version. [entry.py](entry.py) runs the common official client.
See the [runtime contract](../../docs/official-runtime.md) and
[installation and launch instructions](../../README.md).
