# press_by_number

Read `workflow.json` and the seven task skill contracts. `controller.py` exposes
restricted public `resolve` and `run` interfaces. There are no legacy module
aliases, teacher inheritance chains or copied official runtime files.

Qualify current number-card associations and contact surfaces, then prefer
`button_view` or `press_card_button` before a learned recovery. Keep the
original approach/press/hold/release recipe in `press_stroke` and the current
evidence checks in `read_button_counts`. The official evaluator, not command
counts, determines task success and score.

Use the root `model.py` / `eval.sh` official adapter for execution.
`entry.py` delegates to the common official client with this task selected.
`composition.json` declares executable bindings; Git identifies source versions.
See the [runtime contract](../../docs/official-runtime.md).
