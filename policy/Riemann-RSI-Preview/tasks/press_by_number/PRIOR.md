counts and a subsequent blue-button confirmation. This is task development
knowledge, not current scene evidence or an inherited success rate.

- Execute the second red cap's count only after that first confirmation; finish with a separate blue press and complete release.
- Reuse the mature arm preference: the same arm handles both red-count stages, the opposite arm handles confirmation. Current reachability and image preconditions still apply.

- Preserve the mature tool orientation after viewing; complete the bounded down path and hold/release rather than repeatedly chasing a contact pose with a free-space reach test.
- Preserve completed pose-qualified command reports across prompt-cache eviction; do not restart the first count merely because its message is no longer in the last prompts.
- Match completed command reports to the ordered workflow prefix. A completed first blue confirmation cannot stand in for the final confirmation.

button activations, contact or reward. If preconditions or execution remain
uncertain, inspect current public images and use only the bounded recovery
