# Original instrument rule skills

Continuous mature pickup/lift and transport setup precede eight external workflow strokes. The original Model worker retains one feedback ACK per action. Fixed public RGB/robot observations and calibrated geometry are used; gripper command interpolation is not contact measurement.

[composition.json](composition.json) declares the executable bindings; Git identifies
the source version. [entry.py](entry.py) runs the common official client.
