# organize_table

The current public factory is `controller.create_public_environment`; `controller.create` builds the mature episode.
`workflow.json` is the sole primary graph. Its stages call the task skills registered in `composition.json`.
`bindings/profile.json` declares the unchanged motion parameters. Runtime locks and the public observation contract are in `bindings/`.
Only public observations and own commands enter policy execution. The official SDK owns completion, success and reward.
