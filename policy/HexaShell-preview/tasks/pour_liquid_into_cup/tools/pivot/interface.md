## Tool: pivot
`robo pivot <arm> --x X --y Y --z Z --angle DEG [--axis x|y|z] [--frame world|tool] [--step DEG] [--hold SEC] [--finish auto|stay|untilt] [--to_x X --to_y Y --to_z Z] [--transfer arc|staged] [--extent M --radius M --support_z Z] [--clearance M] [--obstacle_xmin X --obstacle_ymin Y --obstacle_zmin Z --obstacle_xmax X --obstacle_ymax Y --obstacle_zmax Z --tcp_radius M] [aiming fields below]`
Rotates a rigidly attached world reference (x,y,z), within .35 m of TCP; optional destination requires all to_* coordinates within .5 m of the reference. Without destination the reference stays fixed. Units: meters, degrees, seconds. Axis defaults y, frame world; tool axes are initial pointing x, opening y, cross-product z, resolved after staged transfer.
Angle +/-150; step default 10 (3..15); hold default 0 (0..2). Transfer defaults arc: descending paths align laterally, descend at a constant intermediate angle, then finish rotation; ascending paths rotate in place, lift, then traverse. Intermediate angle defaults to half the requested angle; guards can change it. Unmonitored constant-angle vertical legs use one straight move; dense geometry checks remain.
Ascending staged nonzero transfers lift at fixed orientation in one move, then rotate during lateral travel at destination height; returns transfer_order=lift_then_rotate_while_translating and vertical_lift_m. Other staged transfers traverse at the higher endpoint height and descend before rotation. Staged paths have no geometry clearance guard; server IK subdivides straight moves at <=2 cm, with tracking checked at move end.
Finish default auto reverses the final rotation leg after the hold for descending nonzero arcs; other paths stay. Stay disables reversal; untilt requires a descending nonzero arc. Reversal ends at via_angle_deg, not necessarily upright. completed_angle_deg is net rotation; successful descending stay returns fixed_reference_recovery command/args at measured reference, valid only before further motion.
Optional arc envelope requires extent (0,.5], radius (0,.2], support_z together; cylinder extends from reference toward TCP (separation >=.01). Clearance default .01 (0.. .1). Plane reserve is .01 + 2*hypot(extent,radius)*sin(2.5 degrees) + .005; no feasible intermediate angle returns envelope_clearance before motion. Plane model excludes the hand and raised obstacles.
Obstacle guard additionally requires six ordered world AABB bounds and tcp_radius (0,.3]; models attached capsule and TCP-centered hand sphere with tracking reserve and dense swept-path padding. Rejects infeasible paths with obstacle_clearance. Requires calibrated head depth and >=30 visible anchors; checks after waypoints and every <=.2 s of hold. Stops on >=20% surfaces vacated by >1 cm, visibility below 30 or 25% anchors, or missing depth; returns obstacle_changed/obstacle_occluded/obstacle_observation_unavailable. Occlusion is not pose verification; bounds must include unseen surfaces.
Optional aiming fields (all required together, each with --): target_x/target_y/target_z, source_z, dir_x/dir_y/dir_z, speed_min/speed_max, target_radius, source_radius, position_error, direction_error. Delegates to aimed_pivot and its ranges/sweep checks; requires extent/radius/support_z and arc, forbids to_*. Direction describes emission at final angle, speed is m/s. Invalid/nonfitting bounds fail before motion; accepted footprint returns aiming and landing_checked=true. Geometry-only calls return landing_checked=false.
Returns plan_ok/plan_fail_reason, stage errors, requested_finish/resolved finish, rotation_axis_world, completed_angle_deg, reached_tcp/reached_reference; guarded calls add via_angle_deg, envelope_axis_world, envelope_reserve_m, envelope_margin_m and optional obstacle/watch diagnostics. References assume rigid attachment; plan_ok and landing_checked do not verify attachment, transit containment, delivered amount or completion.
Stops on planning failure, clipping, >1 cm reference error, >5° orientation error or episode end; failure can leave partial motion. Arc reference increments <=2 cm except consolidated vertical legs; vertical_stops_removed reports omitted stops. Motions/holds cost action steps; no retry or gripper change. Supplied geometry and depth checks are not full-scene collision guarantees.
