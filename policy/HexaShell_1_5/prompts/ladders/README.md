# Score ladders

The 42 task files here are the RoboDojo wiki text of each task (capability dimension, description
and scoring table), copied byte for byte from
[RoboProbe](https://github.com/RoboProbe/RoboProbe/tree/52300752080325086095854e01977a8cf281b684/policy/RoboDojo_Agent_L3_Inspect/recipes)
at commit `52300752080325086095854e01977a8cf281b684`, under the Apache-2.0 license in `LICENSE`.
`manifest.json` holds the SHA-256 of every file; `hexashell/runtime/card.py` refuses a file that
does not match.

The task card of prompt B carries the "Capability dimension", "Description" and "Scoring"
sections of the episode's task (`_random` variants use their base task's file).  The `## Notes`
sections that six files end with were written by RoboProbe for its own agent and are left out.
