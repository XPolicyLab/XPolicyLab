## Stable core: execution and acceptance
1. Read the CURRENT language mapping and RGB; locate objects and intended baskets anew. Use only official16-frame video ICL as visual reference. Do not replay historical coordinates, infer live reward from video, or query object ground truth for control.
2. Assign arms/order from reachability and clearance. Paired actions are suitable only in well-separated regions; the sync guard is not a full swept-collision check. Park the other arm before cross-table transfer. Keep a reachable staging option if direct transfer cannot be planned.
3. Approach a suitable body/strap region, close, lift and verify visible retention. Opening/contact alone is insufficient, especially for thin straps; timeout remains uncertain. After any failed/partial motion, read actual pose before dependent actions. After repeated similar failures, change grasp/approach/order instead of identical retries.
4. Lift BOTH object and entire gripper clear of the basket rim before horizontal transport. Keep clearance before rotating after release. Do not substitute TCP height for swept clearance. Low diagonal lift/carry caused a black-watch rim collision in the archived evidence.
5. Place into the instruction-selected basket, release, inspect current retention/containment/stability, then clear the rim before reorientation. Low release does not guarantee a flat car; visual tilt alone does not prove native failure. Avoid rim/edge placement. Final category identity and score come from native diagnostics, not guesses.
6. Reset using the installed joint-goal homeplan when available; it has one complete same-layout success. Never assume a fixed reset cost or universal reachability. Replan from actual state when a path fails. The evidenced white-basket exit recovery is an explicit forward/up clearance waypoint before turning; dimensions and reachability must be re-estimated, not copied.
