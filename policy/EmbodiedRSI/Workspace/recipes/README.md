# Public RoboDojo recipes

These 42 recipe files are copied verbatim from [RoboProbe/RoboProbe](https://github.com/RoboProbe/RoboProbe/tree/52300752080325086095854e01977a8cf281b684/policy/RoboDojo_Agent_L3_Inspect/recipes), commit `52300752080325086095854e01977a8cf281b684`. `manifest.json` records upstream attribution and file SHA-256; `LICENSE` retains the upstream Apache-2.0 license.

Each Test workspace appends the selected task's recipe to `instruction.md`. Random variants use the base task's recipe and experience.

Some upstream Notes refer to the original L3 agent's tools or pre-sampled frames. EmbodiedRSI exposes only the three primitives in its own manual: `get_instruction()`, `get_observation()` and `step(action)`.
