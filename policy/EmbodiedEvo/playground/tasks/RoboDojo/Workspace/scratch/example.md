# Scratch

Use this directory for temporary analysis and notes for the current scene:

- estimate target positions, sizes, directions, and thresholds from observations;
- save cropped or annotated images and simple statistics;
- record execution results, failure causes, and next steps.

Do not modify `observations/` or write rewards, ledger data, or test seeds here.
Put reusable code in `skills/`, lessons in `lessons/`, and the submission in
`submission/`.
