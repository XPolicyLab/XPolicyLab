# Supported transfer staging
Include ee_control.py and supported_transfer.py, then initialize grip_targets to intended commands. stage_held_object takes the donor side and an absolute placement EE pose in metres/scalar-first quaternion. It keeps the measured orientation during the carry and refuses a placement with a materially different orientation. The user must identify a clear reachable table region and visually confirm a retained grasp before calling it.

The helper moves above placement, lowers while closed, opens only if measured placement was reached, then retreats vertically before any sideways movement. It stops after motion failure and retains closure if placement was not reached. Reserve carry_steps + lower_steps + release_steps + retreat_steps native actions before calling; native episode end is handled by underlying helpers. The returned boolean indicates EE retreat convergence, NOT object placement or task success. Inspect the current head frame before choosing the receiving grasp, because settling changes object pose.

Evidence for the composed procedure: 000093 confirmed cream retention while the opposite arm moved; 000094 staged the bottle centrally with a vertical donor retreat; 000095 retained the subsequent receiver grasp. Earlier 000055-000058 also demonstrated a cream table transfer and bin release. The wrapper itself has not been invoked end to end; its constituent controller pattern was observed. Transfer to other objects/scenes is unverified. Upright transfers and abrupt wrist reorientation were unreliable and should not be inferred from this evidence.
