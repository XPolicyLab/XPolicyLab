## 任务与工具

目标是在550个原生动作内把三个不同纹理方块叠成稳定、已释放的堆叠，
最后双臂归位。任务不规定纹理顺序，优先选现有可达、稳定方块为底座，
避免为底座额外搬运。

- `set_stack_plan`：记录当前三物体身份、底座和初始两次搬运顺序。
- `prism_localize`：结合当前顶面四角、相机标定、支撑平面及明确形状假设估计几何。
- `stereo_localize`：三角化两个当前图像中的同一物理点。
- `plane_localize`：将当前像素投到已测水平面。
- `table_plane`：RGB测量桌面；不把桌面高度当成新堆叠顶面。
- `top_pick` / `settled_pick`：完整接近、下降、闭合和抬升。
- `review_state`：结合当前图像及前后诊断，记录持有或稳定放置的视觉证据。
- `top_place`：按支撑高度和持物模型搬运、释放、垂直撤回并停放。
- `inspect_image`、`move`、`point`、`home`：必要的查看、空手视角调整与合法收尾。

所有几何都是带条件的估计，不是隐藏物体坐标。立方体比例1只有在当前外观
确实支持时才适用；错误角点、比例、遮挡和标定偏差不会被形式上的拟合通过消除。
只使用RGB及公开机器人/相机状态，无仿真深度、物体真值或布局答案。

## 成功执行路径

1. 从当前图像选可达的既有底座和搬运顺序，测量源块中心、顶面及高度。
2. 完整抓取后看新RGB，不以夹爪闭合/TCP抬升代替持有证据。
3. 支持持有的视觉复查通过后执行放置；释放后确认堆叠状态并测量新支撑。
4. 重复第二次搬运；最终释放、垂直撤回并归位双臂。

放置高度使用`support_z + held_height - inset + .002`，以物体保持竖直、
居中且夹持关系未变为前提；发生滑移或倾斜就不能沿用这个模型。
不额外添加按钮按压任务的指尖补偿。第一次放置按场景需要retreat/让位，
最终放置采用both-home。每个实际动作保留原有机器人安全检查。

seed0按上述两次搬运路径成功。seed1先发生跨侧放置IK失败，安全暂放后由右手重抓；
首次两块堆叠又倒开，随后放回手中方块、重新测量和重建，最终在533步成功。
两次最终工具均因原生成功终止而收到episode_over；不能单凭该字段判定成功或失败。

## 失败经验与尚存限制

- 旧v3 seed0/1在定位阶段各10次调用后结束，没有进行抓取；并非以前完全没有
  RGB定位工具，而是材质特征与附件前置条件没有被已有工具满足。
- 本版以已实现的prism/stereo/plane几何和抓取/放置后的图像检查替代旧三材质
  特征前置流程。这是明确的任务层证据策略变化，不声称保留了旧版全部附件验证。
  关节、桌面、碰撞、原生550步及评分规则未放宽。
- 当前计划锁定过于严格：seed1持物时想调整剩余纹理层级被拒绝，导致额外暂放。
  身份不变不应必然等于顺序不可变，但本发布版本保留已测逻辑，没有未复测地修补。
- confirmed_placements保留历史确认，堆叠倒开后不能等同于当前有效层数。
  运行判断必须依赖最新图像和几何，不能依靠历史列表推断任务已完成。
- seed1只余17步，且某些几何估计仍为厘米级敏感度。初始用臂/基座选择、
  跨侧路线预检查、释放稳定性和有界重规划仍有优化空间。
- released=true不是稳定堆叠，review_state也只是模型视觉报告，不是原生真值。
