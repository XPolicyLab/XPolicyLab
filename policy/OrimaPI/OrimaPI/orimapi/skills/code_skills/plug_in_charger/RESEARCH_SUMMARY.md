# plug_in_charger：正式实验skill

## 插充电器：抓本体—测插脚/插孔框架—极性对齐—轴向插入到支撑

**按用户要求合入；尚无此版本的原生仿真得分，seed0/1/2均未测，不宣称任务成功。**

## 职责分工
GPT负责整体任务拆解、目标粗识别、顺序/用臂和恢复规划；本地工具负责精定位与完整操作。
共享执行库是`common/planned_local_v1`，不依赖研究目录运行。

## 任务路径

1. Identify charger body, directed prongs and intended socket from current RGB.
2. Pick the body leaving prongs clear, then inspect actual carried pose.
3. Measure three directed prong/socket frame features from fresh RGB. Do not use object centers or an arbitrary gripper yaw as insertion orientation.
4. dock performs rigid feature alignment outside the socket, axial entry and advance to current visible seat (plug shoulder aligned with socket support); then release/retract.
5. Inspect seating and slip. Correct geometry/grasp after failure, rather than repeating the same unreachable orientation. Home only after supported release.

## 实际接入的本地工具

pick, dock, place, inspect, measure_feature, view, home, wait。
RGB区域/GrabCut、多视角尺寸与位置、自动水平面点匹配或显式双视角亚像素三角化；
轮廓不可用时可提交六个当前可见物体特征获取尺寸。自由空间用原生cuRobo完整规划，接触用线性路线。
RGB桌高未知时明确采用公开场景桌高校准，不把箱底/插孔/抬起篮子当作桌面。
不新增桌距、到位误差、保护步数或重试次数硬门槛；原生物理/评分/动作上限和关节/自碰/双臂守卫不变。

## 失败经验与恢复

Reference mate-pair preflight passed without verified seating; repeated plane-height measurements mostly failed. Explicit paired RGB features recovered measurements, not insertion.

完整操作返回原始工具错误、实际执行阶段、持物/释放假设和当前观察，再交GPT选择不同的可执行恢复。
显式看清夹空可修正持物假设；遮挡/不确定不自动终止。运动/释放完成不证明保握、容纳、承重或座合。
