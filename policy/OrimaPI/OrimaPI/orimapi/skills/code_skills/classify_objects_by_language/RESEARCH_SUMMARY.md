# 语言指令分类：OrimaPI 正式子技能

## 使用范围与执行方式

仅适用于 `classify_objects_by_language`，不替代普通 `classify_objects`。
正式入口为 `controller.py:create_policy`，注册和冻结清单为 `skill.json`。
运行时不读取研究目录或外部参考仓库；工具实现、接口证随技能打包。
仍需项目公共运行时、RoboDojo 公开机器人资源、原生 cuRobo 和配置好的 LLM。

1. 从实时语言指令建立类别→篮子映射；不固化历史场景的类别、像素或坐标。
2. 首次请求向模型提供冻结的历史经验、操作手册和任务规则。
3. 模型用持续 Python 会话保存本场景的测量结果、函数和进度，调用 RGB
   几何工具与受保护的机器人操作。每次交互带回当前图像、状态和执行回执，
   由模型判断重测、调整姿态、继续搬运或结束。
4. 路径执行保留机器人、桌面、完整手指扫掠、双臂及工作空间检查；运动完成
   还需通过跟踪检查。动作回执不等于物体已抓住或任务已成功。
5. 最终成功以原生评测器为准，不以模型的 `done` 或单个工具回执代替。

这是有观察/执行反馈的交互闭环，不是固定坐标开环脚本；也不意味着每个
仿真动作都请求一次 GPT。后续交互时机由本技能决定。

## 已验证路径与工具

seed 0 的模型使用 `table_plane`、`segment`、`locate` 获取桌面、区域与
RGB 几何，使用只读 `reach` 检查可达性，再组合 `goto`、`gripper`、
`move` 和 `home` 执行抓取、抬升、搬运与释放。最终汽车、手表、狮子
都完成语言指定的分类，原生评测 100 分、success=true。

这里固化的是可以重复调用的能力和反馈接口，不是把该次在线生成代码中的
场景坐标写死。可用工具共 10 个模块、16 个扩展命令：
`table_plane / scene / rgb_point / rgb_quad / boundary_candidates /
rim_geometry / guarded_grasp / guarded_press / bounded_rotate / timed_pick`。
另提供基础机器人命令、观察、诊断图像与受限 Python 会话。完整参数见
`tool_documentation.md` 和 `program_prompt.md`。

`grasp_point`、`place_point` 等组合工具虽已打包并通过 CPU 测试，但这两次
原生运行没有调用它们；不能把成功归因于未实际使用的宏操作。

## 实测证据与失败经验

冻结候选 c009；运行 `runs/classify-language-open-profile-c009-20261026`：

| seed | episode | 原生分数（0–100） | 完整成功 | GPT 请求 | 最后工具动作步 |
|---|---|---|---|---|---|
| 0 | 1 | 100 | 是 | 41 | 993 |
| 1 | 1 | 40 | 否 | 45 | 1099 |

均未超时。平均 70 分、完整成功 1/2，仅为两次小样本结果，不代表官方全量
成绩或三 seed 达标。seed 2 未测试。用户明确授权后发布，未新增仿真。

- seed 1 手表、巧克力完成，辣椒未完成；最后一次辣椒搬运在 step 1041
  出现笛卡尔跟踪失败，位置误差约 10.57 mm，随后释放和回位时预算已接近耗尽。
- 单相机可见、机器人遮挡、不可达姿态及安全预检失败都曾发生。工具错误应作为
  后续观察/规划输入，不能当作动作已完成；运动回执正常也不保证抓牢、落篮。
- seed 0 最后 `home` 回执报告未局部收敛（joint_error 约 0.5638），但原生
  评测已判任务成功。保留两种证据，不能把它描述为严格关节回位验证通过。
- 真正的手指停止/开度传感器反馈不可用：`fingers_stopped/opening_m` 为
  `None`；原生夹爪字段是命令值，`gripper_seen` 只是 RGB 估计。
- 旧候选 005–008 的失败不是本版本的成功证据，也不提供可直接复用的坐标。

上述新增复盘仅作发布说明，**没有改动已测试的 `experience.json` 注入内容**，
避免固化时悄悄改变模型行为。未来若修改提示词或注入经验，应重新验证。

## 固化边界

代码、提示词、工具默认值、运行参数和注入经验保持 c009 的已测版本。
原生预算 1100 动作，模型请求上限 500（不是实际请求次数）；单 task-seed
最长 150 分钟由评测启动器设置，清理时间另留。图片 300000 bytes、
整个请求 2000000 bytes 的现有传输限制保留；诊断裁剪不改变几何标定。
Python 会话保留 AST、内存、数组和每 cell 128 次工具调用等边界；
不允许任意 import、文件访问或私有属性。

来源和移植边界见 `NOTICE.md`、`source_provenance.json`。
我们维护本地控制器、受限会话和原生适配；保留上游工具署名及 本地
许可，不冒称复现了未公开的原服务端。所有运行资源已本地打包。
`publication.json` 记录旧正式版备份、冻结候选哈希和逐文件运行哈希；
`validation.json` 保存两个 seed 的观测结果。发布元数据改变 bundle 哈希，
不改变测试过的算法。本次无迁移后的额外原生仿真。
