# c008 发布经验

本文件是发布说明；模型实际使用的experience.json保持已测字节不变。

- 约束对象是碗口方向，允许水平转角；不能将其等同于固定完整夹爪朝向。
- 先尝试自由朝向的直线IK，再用绕障规划器处理受阻路径。
- cuRobo轴顺序为x/y/z/roll/pitch/yaw，途中XYZ跟踪权重为0，yaw不固定。
- 运动失败后更换本地动作，不反复复核同一持碗画面后重发同一目标。
- 原生步数由仿真结束规则控制；重测失败可沿用已确认位置，不增加测量成功门槛。
- 本批58次实际持碗动作采用直线分支，4次绕障用于空手观察/回位。整体提升不能单独归因于绕障规划器。
- 初始定位及最后一次放置仍有失败；不宣称完整场景避障或完整官方资格。
