`robo stereo-feature {point,segment,body,line,plane} --peer CAMERA --u FLOAT --v FLOAT --pu FLOAT --pv FLOAT [--camera head] [--u2 FLOAT --v2 FLOAT --pu2 FLOAT --pv2 FLOAT] [--color_tolerance 65]`
Read-only calibrated RGB stereo; no depth input, assumed height, motion or action steps. Coordinates are world metres and pixels; cameras accept head, wrist_l, wrist_r, their .png names or observation source names.
point matches u/v with pu/pv and returns point_world; segment additionally matches u2/v2 with pu2/pv2, returning endpoints_world, center_world, length_m and input-order signed axis_world. Selections must identify the same current physical features.
body seeds the same uniform-color elongated span in both views and uniquely pairs fitted endpoints. line seeds the same straight colored axis, requiring an unclipped primary span; peer may be shorter/clipped, with extrapolation capped at half its span.
Body/line return center_world, endpoints_world, arbitrary-sign axis_world, visible_length_m and region diagnostics; full_geometry_verified=false. Line measures primary-view extent and returns peer_span_fractions and correspondence_verified=false.
color_tolerance is 5–150: RGB distance for body/line, normalized-color distance min(0.15, color_tolerance/500) for plane. Body/line require aspect ratio ≥3, span ≥16 pixels and regular silhouettes; body requires unique pairing.
plane seeds the same complete colored rectangular outer surface in both views; triangulates boundary corners, excluding interiors. Rejects clipped/small/nonrectangular/nonplanar or ambiguous boundaries; common full-boundary visibility is assumed.
Plane returns plane_point_world, normal_world, plane_offset_m, corners_world, plane_max_error_m, height_span_m and horizontal_height_m (null if tilt >5°).
Diagnostics include ray_gap_m, ray_angle_deg, reprojection_error_px, one_pixel_sensitivity_m and extent/axis sensitivity where applicable; line sensitivity also perturbs peer fitted endpoints by ±1 pixel.
Returns plan_ok/plan_fail_reason; invalid input, baseline <20 mm, ray angle <5°, behind-camera intersections, gap >10 mm, reprojection >2 pixels or sensitivity >15 mm fail. Line also rejects epipolar angles <15° or excessive extrapolation.
Sensitivity excludes segmentation/calibration bias and incorrect matches; identity, hidden geometry, retention and free space remain unverified.
