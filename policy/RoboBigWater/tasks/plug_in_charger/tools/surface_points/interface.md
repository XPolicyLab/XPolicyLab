Read-only calibrated geometry; no motion steps or command budget. Cameras: head, wrist_l, wrist_r or exact observation keys; meters, image pixels, integer upper-exclusive ROI bounds. All commands return plan_ok/plan_fail_reason; malformed inputs, missing calibration/depth or unreliable geometry fail.
`robo surface-points --camera NAME --pixels '[[u,v],[u,v]]' [--roi '[u0,v0,u1,v1]'] [--frame_arm left|right] [--base_pixels JSON] [--base_mode endpoints|surface|single|plane|extrema] [--radius PX] [--refine_endpoints 0|1]` returns points_world, midpoint_world, separation_m; ordinary ROI mode fits a dominant plane and intersects rays, requiring pixels inside ROI. Raw depth may include occluders/background.
Rear/forward modes return measured axis_world, baseline/residual and `source_geometry={points,axis,frame,arm}`; frame_arm adds points_local/axis_local and tcp_at_measurement, with bundle frame=tcp. Without frame_arm the bundle uses world coordinates. Plane fits return plane point/normal/RMS/inlier fraction.
endpoints (default) requires two corresponding rear base_pixels and no ROI; surface removes bounded transverse rear sampling offsets. Both reject spacing <3 mm, baseline <5 mm and inconsistent unequal/nonparallel/nonperpendicular segments. single takes one rear pixel corresponding to the FIRST forward point, baseline 5..80 mm, and assumes parallel extensions.
plane requires two forward pixels plus rear-face ROI, no base_pixels; assumes perpendicular extensions with compatible 5..80 mm standoffs. extrema additionally extracts supported seed-connected forwardmost regions, radius=12 (3..24); sparse/cropped/inconsistent extents fail. Forward seeds may lie outside rear ROI.
`refine_endpoints=1` attempts supported forward-extents refinement in endpoints/surface with paired rear samples and in plane mode, radius=12 (3..24). Both ends must advance >=2 mm and pass consistency; otherwise clicked geometry remains explicitly unverified. Set 0 for raw samples. Visible extents may be occlusion boundaries; feature identity and endpoint visibility are unverified.
`robo plane-pair --camera NAME --roi '[u0,v0,u1,v1]' --separation M [--tolerance M] [--contrast N] [--pixels '[[u,v],[u,v]]'] [--radius PX] [--frame_arm left|right]` projects enclosed dark-region centers onto a bright fitted plane, rejecting foreground; only a unique spacing-compatible pair succeeds. Separation 0.003..0.2; tolerance=0.002 (0.0005..0.005, below half separation).
`contrast=0` searches 10/20/40/60/80/120, requires >=2 levels with center spread <=1.5 pixels and <=tolerance/2; explicit contrast 10..200 uses one level. Optional two seeds constrain centroids to radius=4 (1..12), preserve seed order, require seeds inside ROI and spacing >2*radius; unseeded order is nonsemantic. Ambiguity/instability fail. Returns pair geometry, plane/threshold diagnostics, candidates and bounded rejected-region/near-pair diagnostics; failures omit top-level points_world.
`robo feature-pose ARM --points_local '[[x,y,z],[x,y,z]]' [--axis_local '[x,y,z]'] [--depth_tolerance M]` predicts world points/axis through current TCP; ARM=left|right, depth_tolerance=0.01 (0.002..0.03). All features in observed free space in one camera fail rigid_capture_contradicted, returning predicted_points_world instead of points_world. Returns depth_views and attachment_status=contradicted|depth_consistent|unverified; occlusion is inconclusive and visual_verification=false.
`robo stereo-points --camera NAME --pixels JSON --other_camera NAME --other_pixels JSON [--tolerance M] [--frame_arm left|right] [--base_mode endpoints|surface]` triangulates 2 corresponding forward points, optionally followed by 2 rear points, from distinct cameras in one observation; four points also return axis/source_geometry. Tolerance=0.002 (0.0005..0.005); ray/depth gaps above tolerance, reprojection >1 pixel or near-parallel rays within 10° fail. Returns geometry, ray_gap_m, triangulation_angle_deg, stereo_views; correspondence, feature identity and rigid attachment remain assumptions.
