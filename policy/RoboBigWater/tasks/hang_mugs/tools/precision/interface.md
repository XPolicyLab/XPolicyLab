`robo surface --pixels 'U,V;U,V' [--camera head|wrist_l|wrist_r] [--pixels2 'U,V;U,V'] [--camera2 head|wrist_l|wrist_r]`
Free RGB-D conversion of 1–32 visible pixels; returns samples and world_mean. Empty image regions measure background. pixels2 triangulates ordered identical physical locations across different current cameras, ignoring depth values; silhouettes are not correspondences. Stereo rejects ray gaps >3 mm, parallax <10°, reprojection >1.5 px, behind-camera intersections or invalid pairs; returns measurement_mode and error diagnostics.
`robo aperture --rim 'U,V;U,V;U,V;U,V;...' --center U,V [--camera head|wrist_l|wrist_r] [--rim2 'U,V;U,V;U,V;U,V;...'] [--camera2 head|wrist_l|wrist_r] [--plane 'U,V;U,V;U,V;U,V;...'] [--plane2 'U,V;U,V;U,V;U,V;...'] [--snap auto|0|1|2|3|4] [--depth_range MIN,MAX]`
Free convex planar-opening measurement; 4–32 distinct rim pixels surround center. Returns center, normal, inner_radius_lower_bound_m, plane_valid, clearance_valid and fit/sampling diagnostics. plane fits an enclosing coplanar solid face and projects rim rays; clearance is capped by both hulls. rim2 triangulates rim; plane2 requires plane and triangulates face; these stereo modes are mutually exclusive and obey surface stereo limits. Correspondences and coplanarity are caller contracts. Depth modes use bounded consensus (outlier/omission removal requires ≥6 inliers and ≥75% original selections); snap=auto tries 2 then 4 pixels only after insufficient plane consensus, numeric 0–4 selects one radius, 0 disables. depth_range selects inclusive camera-Z meters (0<MIN<MAX), excludes stereo and never alters the raw-depth interior veto. Coplanar interior evidence rejects geometry. Ambiguous/nonplanar/edge-on fits or outside centers fail; exhausted clearance returns plan_ok=false, plane_valid=true, clearance_valid=false, radius=0 and remeasure_required. Local sampling subtracts calibrated pixel/residual uncertainty; no semantic correctness or thickness correction is established.
`robo grasp <arm> --xyz=X,Y,Z [--approach auto|down|down45] [--open x|y] [--transit combined|staged] [--clearance 0.10] [--lift 0.12] [--lift_rpy=0,0,0] [--verify_pixels 'auto|off|U,V;U,V;U,V;U,V'] [--verify_camera head|wrist_l|wrist_r] [--tolerance 0.012]`
Raises to max(current Z,Z+clearance,Z+lift), orients/traverses, opens, descends, closes and lifts; combined merges rotation/travel, staged separates them. Auto tries down then down45 only after motionless pre-descent IK rejection. lift_rpy applies world Rz·Ry·Rx degrees (±180) during lift; rotating clearance is caller supplied. Verification defaults auto (4–8 coherent local patches); explicit 4–32 solid-surface pixels override selection, off disables. Lift evidence requires ≥75% vacated-origin/occupied-destination agreement; recovery allows one common translation ≤30 mm, with each current camera evaluated independently. Returns visual_lift_consistent, evidence_camera, verification_views, translation_correction_m and remeasure_required; inadequate evidence fails with visual_lift_unconfirmed, retaining grip. Positive evidence does not establish identity or secure retention.
`robo align-feature <arm> --source=X,Y,Z --target=X,Y,Z [--standoff=0,0,0.04] [--phase approach|finish] [--release 0|1] [--retreat=0,0,0.06] [--tolerance 0.008]`
Orientation-preserving translation. Approach defaults to target+standoff, forbids release and returns predicted_feature/remeasure_required. Finish requires freshly measured source within 0.08 m of target, ignores standoff, translates and optionally releases/retreats. Freshness is caller supplied; no insertion geometry is inferred.
`robo insert-feature <arm> --source=X,Y,Z --normal=X,Y,Z --base=X,Y,Z --tip=X,Y,Z --depth M --radius M --shaft_radius M --thickness M [--phase approach|refine|insert|finish] [--orient keep|normal|fit] [--twist 0] [--twist_search 0|1] [--transit combined|staged|raised] [--travel_clearance 0.08] [--clearance 0.03] [--seat=0,0,0] [--release 0|1] [--retreat auto|X,Y,Z] [--tolerance 0.008]`
Source/normal define a freshly measured plane; base→tip is outward cylinder axis. Requires radius>shaft_radius+tolerance and finite oblique-slab clearance; depth is 0.002–0.8*axis-length m. Approach retains grip outside tip, forbids seat/release/explicit nonzero retreat, returns predicted_feature/normal/insert_tcp and remeasure_required. keep preserves orientation; normal aligns fully; fit rotates minimally. Combined normal/fit approach allows bounded twist alternatives only after unchanged TCP/joints and unclipped IK rejection (normal ≤8 across both plane branches, fit ≤4; twist_search=0 disables). Staged separates rotation/travel; raised (approach only) adds vertical raise/cross/descent with travel_clearance=.02–.30 m and no alternatives. Refine requires normal|fit, combined, ≤30° rotation, lateral ≤.03 m, axial ≤.15 m and axial>radius+thickness/2+tolerance+4*TCP-source-distance*sin(rotation/2); compensates translation, forbids twist/seat/release/explicit nonzero retreat, then requires remeasurement. Insert requires keep, zero twist, fresh source lateral ≤.03 m and axial .002–.15 m; corrects outside tip, inserts/seats, always retains grip and defers release. Finish requires keep and zero twist, uses fresh source/normal to validate finite-axis penetration/eccentricity, forbids seat, preserves pose and optionally releases; invalid engagement fails before release. depth is required but unused by refine/finish. Auto retreat only after finish release moves .10 m opposite current tool +X; explicit world vector overrides, zero disables. Returns stages, fit/engagement, release_performed and withdrawal diagnostics; modeled acceptance does not establish exterior clearance or stable placement.
Arm=left|right; cameras=head|wrist_l|wrist_r (camera defaults head, camera2 wrist_r); world vectors/meters, unitless normals; use = before negative vectors. Calls return plan_ok/plan_fail_reason. Motions cost action steps, return reached_tcp/stages and stop on failure, clipping, position error above tolerance or rotation error >5°; grip is retained before release. Invalid inputs fail before motion. Measurement freshness, correspondence and swept-volume clearance are caller contracts; physical success remains unverified.
