`robo grasp_at ARM --x X --y Y --z Z [--heading 0 --clearance .10 --lift .10 --backoff .10 --surface_allowance .05]`
`robo place_over ARM --x X --y Y --z Z --rim_z H [--below .05 --margin .03 --yaw 0 --tilt 0 --turn_order tilt_first --yaw_route auto --retreat .05 --backoff .18 --route_radius .05 --route_depth advisory --target_rotation JSON --y_slack 0]`
ARM: left|right; coordinates: absolute metres; angles: degrees. Heading is finger-opening direction from +x toward +y. Clearance/lift/retreat: .03–.30 m; backoff: .03–.20; surface_allowance: .004–.30; below: 0–.30; margin: .015–.15; route_radius: .01–.30.
Grasp raises, retracts to y=min(current_y,Y-backoff), orients, aligns x, adjusts to Z+clearance, advances, opens, descends, closes and lifts. Caller clearance covers forward travel. Visible geometry above Z+surface_allowance can fail before motion; unchanged source depth can fail after lift. Missing/occluded/sparse depth is unknown, never verified retention.
Placement commands closure, raises, retracts, turns, aligns x, advances, releases at max(Z,effective_rim_z+below+margin), then rises by at least retreat. Transit height is max(initial z,release z). H covers route obstacles; below includes all downward extent during turns/transit. No collision, containment or landing guarantee.
Route_depth advisory|enforce returns route_check with raw max_z and suggested_rim_z; advisory retains H, enforce uses max(H,observed height). Unsegmented depth can include robot geometry and demand unreachable heights; missing depth retains H with unknown status.
Yaw is ±180 about global +z then tilt ±45 about global +x; turn_order tilt_first|yaw_first changes the intermediate route. Target_rotation is an absolute proper 3×3 JSON rotation matrix requiring yaw=tilt=0; returned resume_rotation encodes the saved target for this argument.
Bounded IK alternatives require ≤1 mm/0.5° movement: grasp can orient before retracting or tilt +45° before reapproach; placement can change initial tilt to yaw-first, or try opposite yaw winding (yaw_route auto; signed disables winding recovery). No alternatives after clipping, tracking error or exhausted time.
Y_slack permits one alternate release at Y-y_slack after forward IK rejection, at unchanged height/rotation; range 0–min(.10,backoff), default 0; caller accepts both landing extents. A rejected post-release rise permits reverse approach then rear rise only when release equals transit height. Alternatives remain bounded and may fail.
Returns plan_ok, plan_fail_reason, stages, released, release_z/y, approach_y/z, route diagnostics, turn_target_rotation, resume_rotation, turn_remaining_deg and applicable *_route_used/turn_order_used/grasp_tilt_deg. Grasp returns target_check/source_check and grasp_verified=false on unchanged source, otherwise null. Retention_checks combine calibrated depth views after turning/before release; strong visible absence stops with carried_surface_missing and fingers closed; unknown is not proof of retention.
Fails on invalid arguments, motion failure beyond bounded alternatives, clipping, exhausted time, >1 cm/>5° tracking error, target_surface_too_high, source_surface_unchanged or carried_surface_missing. Descent allows 2 cm upward error with ≤5 mm lateral error; release requires ≤5° original-target error. Failures may follow partial turns or release; neither motion success nor depth checks prove grasp or landing success.
