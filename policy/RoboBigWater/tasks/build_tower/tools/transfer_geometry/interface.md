`robo transfer_draft --source_u U --source_v V --target_u U --target_v V --floor Z [--clearance 0.015] [--preferred_yaw 0] [--place_yaw DEG] [--grasp_axis DEG]` computes a six-stage geometric recipe from the current head RGB-D calibration; free, no actions.
Floor is the currently observed table/support reference in world metres. Clearance 0.015–0.30 m; headings -180–180 degrees. Optional place_yaw rotates the visible footprint and checks its public carry corridor. All pixels must be inside the current image.
`--kind bridge --second_u U --second_v V` selects two support tops (target and second) and fits the span axis. Requires <=3mm height difference, >=80% observed overlap and >=1cm geometric-centre polygon margin. Bridge uses measured source/arrival heights: source max(0.90,max(source top,release)+0.031), arrival min(source height,release+0.044); clearance and place_yaw are support-mode inputs. No geometry gate certifies physical stability.
If the connected-object selector merges a neighbouring coplanar region, bridge mode falls back to the current pixel-connected horizontal-face meter, then rechecks measured width against the public gripper opening. The fallback is recorded as `source_selection_path`.
Returns recipe.stages with world tcp_xyz, ee_pose (XYZ plus WXYZ quaternion), gripper command and arrival requirement; source/target support levels, jaw axes and footprint remain measured geometry, not physical success.
Rejects absent/ambiguous support, unsupported size, invalid depth/calibration or out-of-image input with plan_ok=false. A raised target is fitted locally and must cover at least70% of each visible source dimension.
kinematics_checked=false and object_effect_verified=false remain explicit. The caller must preflight each pose and budget, execute through the active primitives, verify lift/place effects and reground after failures. Never replay a recipe across episodes or changed observations.
