## vertical_span
`robo vertical_span --base_u U --base_v V --top_u U --top_v V [--support_z Z] [--support_u0 U --support_v0 V --support_u1 U --support_v1 V] [--fraction 0.5] [--camera head|wrist_l|wrist_r] [--pixel_error 3] [--support_error 0.02]`
Read-only reconstruction of one world-vertical axis from calibrated lower/upper endpoint rays; no action steps. Base lies on absolute world support height in meters; omitted height uses a broad depth band with local evidence. Camera defaults to head.
Optional support_* selects a visible support rectangle: all four values required, ≥12×12 pixels, within 0.20 m of base XY, sufficient valid flat depth/world extent, and unique match within 0.01 m to a broad local band. Caller supplies surface identity; no height-check override.
Reliable explicit-height disagreement >max(0.025,support_error+0.005) m returns support_height_mismatch and retry_args omitting height. Multiple local planes return support_height_ambiguous/support_candidates absent a valid patch; remote bands are excluded. Explicit height works with missing depth, but patches require valid depth.
Returns plan_ok, plan_fail_reason, point at fraction (0–1; default 0.5), base, top, height_m, top_residual_px, support_z, support_estimate, support_check_detail, depth_used and geometry_verified=false.
Inconsistent endpoint pairs fail before support inference with endpoint_diagnostics: normalized gravity lines, perpendicular pixel distances and nearest projections for both selections. Projections are alignment diagnostics, not corrected endpoint coordinates.
`sampled_point_bounds` and `sampled_height_range_m` perturb endpoints/support; these are sensitivity envelopes, not certified bounds. Pixel_error range=0–25; support_error=0–0.1 m, with ≥0.02 m for inferred support. Calibration error, occlusion and wrong endpoint identity are excluded.
Invalid input/calibration, out-of-image uncertainty, short/ill-conditioned span, nonpositive height, inconsistent endpoints, invalid patch or unavailable/ambiguous automatic support fail. No retention/reachability verification.
