`robo surface_line --camera head|wrist_l|wrist_r --u1 U --v1 V --u2 U --v2 V [--radius 10]`: read-only surrounding-plane projection, radius 4–40 pixels; returns center, endpoints, tangent, surface_normal, width_direction, length_m and fit quality; invalid/unsupported depth fails.
`robo align_feature left|right --point=x,y,z --normal=x,y,z --target=x,y,z --target_normal=x,y,z [--mode preview|move] [--path auto|direct|split|clearance] [--twist 0]`: world point/plane alignment preserving rigid TCP offset; preview defaults motionless without reachability testing; twist ±180°.
--reference_tcp accepts 16 row-major measurement-time TCP transform values; omission means current geometry. Propagation assumes no slip.
Paths auto/direct use measured clearance for verified long downward transfers, otherwise a combined goal; split rotates then translates. Explicit clearance requires --clearance=x,y,z, magnitude 0.005–0.20 m; other paths require zero supplied clearance. Paths are not collision checked.
--other_offset=x,y,z (zero default; nonzero 0.005–0.25 m) first translates the peer with fixed orientation, requiring its gripper command ≥0.95 and checked arrival; rebases geometry and preserves the visual reference.
--transfer_twists=0,90,-90,180 accepts 1–8 distinct offsets within ±180°, starting at 0; direct/clearance try unsigned-normal alternatives only after motionless IK rejection. Split ignores offsets.
--verify_pixel=auto selects a supported patch near point; camera,u,v selects explicitly; none disables vision. Verification tests visible surface consistency, not semantic ownership or retention.
--position_tolerance 0.002, --normal_tolerance 0.001 (meters), --angle_tolerance 1 (degrees): positive finite. Final mismatch permits at most one bounded same-goal retry after visual/arrival checks; no overshoot or opening.
Returns plan_ok/plan_fail_reason, stages, executed, requested_path/path, clearance_guard, target_tcp, waypoints, source_tcp/source_feature/source_normal, reached_tcp, achieved_feature/normal, feature/normal errors and visual_verification.
correction_world is target minus achieved feature, not an addition to target_tcp; visible_patch_median is not a center. Fails on invalid inputs, unsupported observations, travel >0.80 m, planning/tracking failure, unsettled arrival or timeout; motion consumes time.
