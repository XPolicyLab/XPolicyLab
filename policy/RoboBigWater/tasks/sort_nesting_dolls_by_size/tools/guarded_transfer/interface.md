`robo guarded_transfer <left|right> --x X --y Y --z Z --to_x X --to_y Y --to_z Z --color surface|yellow|red|green|blue|orange` transfers between world TCP points in metres with an initially open gripper.
Options: `--camera NAME` (head), `--support_z Z` (otherwise inferred), `--radius M` (.01–.12, default .045; verification cylinder), `--payload_radius M` (.01–.15, default .06; carried footprint), `--margin M` (.005–.10, default .025).
Options: `--approach auto|down|down45` (auto), `--open auto|x|y` (auto), `--clearance M` (.04–.25, default .04), `--route auto|direct` (auto). Auto checks down/x, down/y, down45/x, down45/y, restricted by explicit choices; auto routes examine up to seven paths per orientation.
Preflights reach, observed clearance, opposite hand and hand sweeps; then descends, closes, lifts, verifies translation, carries, lowers, releases and withdraws vertically above the observed translated top. No physical retries; motions consume action steps and this command consumes command budget.
`robo transfer_plan <left|right>` accepts identical arguments and performs complete preflight without motion/gripping/budget; returns planning_only=true. Execution recomputes checks; a plan certifies neither grasp nor placement.
`robo contact_pose <left|right> --x X --y Y --z Z --diameter D --support_z Z [--approach down|down45 --open x|y]` converts a horizontal circular section to a nominal opposed-pad TCP; defaults down/x; no motion/budget. Returns tcp_candidate, contact opening/points, finger bottom/minimum contact elevation; fails on invalid calibration, inclined closing axis, aperture or support interference; no reach/scene/stability check.
`robo transfer_clearance --x X --y Y --z Z --to_x X --to_y Y --to_z Z --support_z Z [--camera NAME --payload_radius M --margin M --color COLOR --route auto|direct]` returns observed corridor/height evidence without motion/budget, reach checks or robot-depth subtraction; shared defaults above, omitted color includes all depth.
Returns plan_ok/plan_fail_reason, clearance/preflight evidence, grasp_height (including support_compatible and minimum_tcp_z when calibrated), verification_filter (per-view excluded pixel counts/model availability) and selected_approach/selected_open/orientation_attempts; execution adds stage/lift/release status, withdraw_z, reached_tcp and placement_verified=false. Collision failures include independent last-candidate reach evidence without overriding collision rejection.
Invalid arguments, missing evidence/calibration, above-surface grasp height, finger/support interference at either endpoint, occupied destinations, blocked/unreachable paths or excessive clearance fail; execution also stops on failed/clipped/inaccurate motion or unverified lift. Failure after closure may leave a payload held.
Surface verification uses separate calibrated pre-motion view baselines; hue verification can consult alternate views. Surface corridors include all depth; named-hue corridors include bright chromatic depth; hand sweeps include all depth. Modeled active-arm depth is subtracted from scene checks and pre/post-lift views with endpoint protections; occluded space, model mismatch, full-arm collision freedom and placement stability remain unverified.
