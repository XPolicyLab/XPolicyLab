`robo transfer ARM --x X --y Y --z Z --to_x X --to_y Y --to_z Z [--open x|y] [--clearance .045] [--margin 0] [--lift_scale 2] [--transit_scale 2] [--arch .025] [--close_mid .5] [--other home|keep]`
Grasps, lifts vertically, transits, lowers, releases after a 2–6-step stability check and retracts. World TCP coordinates are metres; z/to_z are grasp-centre heights. Transport height=max(z,to_z)+clearance+.015+margin; arch adds a raised xy midpoint. margin/arch: [0,.10]; close_mid: 0 for direct closure or [.05,.95] for staged closure before 0; staging adds one gripper interval.
With model access, preflights both jaw signs and combined/separate approach rotation, selects lower weighted path cost and retains paths through lowering. Start mismatch above .02 rad or 3 mm/2 degrees fails before the segment. Preflight checks kinematics, not collision clearance or grasp retention; without model access only individual stages are checked.
`robo tap ARM --x X --y Y --z Z [--open x|y] [--clearance .045] [--travel .0085] [--dwell .16] [--tip_offset .013] [--contact_scale 3] [--release_scale 3] [--unload .32] [--surface_speed .02] [--finish retract|home] [--other home|keep]`
Closes jaws, approaches supplied surface z, targets TCP z+tip_offset-travel, dwells with tracking checks, unloads and retracts with jaws closed; finish=home additionally returns active joints. travel: (0,.025] m; dwell: [.04,.4] s; tip_offset: [0,.03] m calibrated closed-tip extension beyond TCP (default X5 .013); unload: [0,.6] s, 0 disables local unloading.
ARM: left/right; open: jaw axis, default x; clearance: [.035,.20] m. Both commands default other=home: return inactive joints unless already within .02 rad; displaced inactive jaws must be fully open. other=keep preserves their pose. All four scale arguments accept [1,4] and stretch their respective Cartesian paths with model access; noncontact settling is 2–8 steps.
Tap surface_speed: 0 disables segmentation or [.005,.05] m/s adds a surface-relative approach and contact/unload duration floors. With model access, contact and enabled unload always retain a .04 m/s mean endpoint-speed floor, combined with requested scaling/durations; instantaneous speed is not bounded. Contact uses two settling steps plus dwell. release_scale=1 permits guarded local clearance return; larger values stretch Cartesian release. Without model access, timing uses base motion.
`robo rest ARM` accepts left/right/both; returns initial joints concurrently at at most 2 rad/s with 2–8 settling steps and .02 rad tolerance; joint returns require a clear route.
Returns plan_ok/plan_fail_reason, stages, reached_tcp, route_preflight, route costs, transport geometry, timing diagnostics and achieved released/returned_home/inactive_returned_home flags. Costs exclude some execution overhead and do not guarantee completion time.
Tap returns contact_reached_tcp, surface_shortfall_m, surface_reached, contact_tip_world, tip_surface_shortfall_m, tip_penetration_m and tip_surface_reached; these describe geometry only. Bounded contact can complete with surface_reached=false. grasp_verified/contact_verified remain false.
Fails on invalid geometry/arguments, unreachable route, stale preflight start, inactive_gripper_not_open, excessive tracking error, release_not_stationary, executor failure or episode termination; no automatic retries. Failed release stability leaves jaws closed; contact failures attempt guarded retraction when execution remains available.
