### Procedures

Solve the current nesting-doll instruction from the ORIGINAL reset. Use RGB, calibration, proprioception and robot tools. Read the shared robot API and this complete procedure; import from library.sort_nesting_dolls_by_size import nesting_skills as ns; use its bounded helpers where appropriate. Skills are not a complete autonomous policy. You own observation, visual identity, rank, swept-path review and recovery.
Maintain a compact checklist: five identities/ranks, CURRENT measured landmarks, grasp/retention, intended row positions, actual released positions/uprightness. do not waste actions. Guards and helper errors return control to you; they never justify giving up or voluntary finish. Never replay an acknowledged or ambiguous motion. Only episode end or a preserved external interruption ends an episode.
First observe all five pieces and rank physical size. They may resemble ducks or gold/red dolls. Perspective changes pixel size; corroborate apparent dimensions with calibrated geometry. A useful measured landmark is the same crown point in head and wrist images. Mark corresponding pixels with visual_tools and inspect the overlays before triangulating with assistive_vision. Pixels are row,col. Reject poor/occluded correspondence and implausible height even when the ray gap is small. SAM3 locate is an alternative, but size adjectives can select the wrong instance; visually check the result. Do not invent exact3D targets from an unverified pixel/depth guess.
Plan a current visually clear horizontal row, smallest at the left to largest at the right as the head camera sees the table, with generous body/jaw clearance and access to UNPICKED neighbors. Use measured support and widths. The same-support translation helper preserves the ACTUAL supported grip pose. It does not infer target height or guarantee a rigid grasp. Pick order is flexible: largest-first is only one candidate, and clearing a small neighbor may be safer. Choose the arm with direct reachable access; supported staging/regrasp in open space is allowed if direct cross-body motion is infeasible.
Available grasp candidates are oblique body pinches at about55–65degree pitch for smaller pieces and vertical (85–90degree pitch) for the largest. These are tested grasp candidates, not universal requirements. Start with a visually verified empty hand and enough open-jaw clearance; the grasp helper does not open automatically. Choose contact from CURRENT visual geometry, preview, approach, close and make a bounded probe lift using ns.grasp_and_probe. Inspect actual object following/uprightness, not merely holding=True. Save its actual grip_xyz and grip_angles for same-support transfer. If the object shifts in the fingers, reobserve/replan rather than preserving a false rigid offset.
After reviewing retention and a clear route, ns.select_transfer_plan previews caller-reviewed row/height alternatives INCLUDING withdrawal. It does not check environmental collision. A nearby free row slot may allow a higher carry; never lower required clearance just to pass IK. Then ns.advance_moves executes a bounded block and returns on uncertain contact. Inspect the placement before a SEPARATE supported release. Withdraw empty fingers without catching a neighbor, then observe the actual released object. Group routine validated moves; spend decisions at uncertain contact, identity, release and recovery transitions. Print compact statuses/replies, not huge preview waypoint arrays.
If a piece is displaced or tilted, preserve completed placements and use fresh marked views to recover. Directed base-to-crown identity matters: do not rotate using a reversed axis. Aperture-zero may still mean a piece is hooked outside the fingers. Set such contact down/open near support and verify disengagement before retreating. Keep recovery over the interior of the table. Empty camera-pose symmetry may point a wrist away; inspect actual pose/reply and use the conditional lesson only for a verified empty hand in open space.
Before home: visually verify all five actually released and supported upright, correct left-to-right size order, a horizontal row and clear arms. Goal for the finished row: total Y spread<35mm and successive X gaps>30mm (the 3.5 cm spread and 3 cm spacing in the task description), every doll standing upright; aim for margins and measurement uncertainty. ns.review_row_centers can reject bad geometry but cannot confirm success. Home is only after this review, not a routine viewpoint reset or success test. If still active, inspect and recover and do not waste actions.
